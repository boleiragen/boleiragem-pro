# boleiragem-pro
App PWA para gestão completa de peladas e futebol com cronômetro, narração e ranking.
⚽ boleiragem-pro
🚀 Funcionalidades Principais
￼ ⏱️ Cronômetro com Apito & Narração: Sistema de áudio dinâmico via Web Speech API e Web Audio API (síntese de voz, apitos de jogo e vinhetas de gol).
￼ 🎲 Sorteio Tático Inteligente: Divisão automática de equipes (Futsal, Society e Campo) e gerenciamento de fila de espera organizada.
￼ 📊 Ranking & Artilharia em Tempo u Real: Acompanhamento de gols, partidas jogadas e histórico mensal e geral.
￼ 📲 PWA Instalável: Funciona diretamente no navegador ou como aplicativo nativo na tela inicial do smartphone (iOS e Android).
￼ 🛡️ Segurança & Controle de Sessão: Proteção contra acessos simultâneos e controle de presença.
￼ 💬 Integração com WhatsApp: Envio com 1 clique do resumo das partidas e da tabela do ranking direto para o grupo da pelada.
🛠️ Tecnologias Utilizadas
￼ HTML5 & Web APIs: SpeechSynthesis API e Web Audio API para narração e efeitos sonoros.
￼ Tailwind CSS: Interface moderna e responsiva otimizada para dispositivos móveis em Dark Mode.
￼ JavaScript (ES6+): Arquitetura Single File sem necessidade de build ou frameworks pesados.
￼ FontAwesome: Ícones vetoriais.
